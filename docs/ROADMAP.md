# 项目路线图

架构总纲：**LLM 当编剧（输出结构化 JSON），Godot 当舞台（确定性代码消费 JSON）。**
世界观是 `lore/` 下的输入文本，可随时替换（当前：符文之地简化转述，仅自用，不公开分发）。

| 阶段 | 内容 | 状态 |
|---|---|---|
| 0 环境 | Godot 4.7.2（tools/godot.exe）、Node、git | ✅ |
| 1 文字故事引擎 | lore→世界JSON+文字冒险；通过标准：5次生成校验PASS率≥80% | 🚧 骨架完成，待真实API压测 |
| 2 Godot程序化地图 | 地貌约束的随机地图 | ⬜ |
| 3 剧本驱动世界 | JSON刷NPC/任务/对话，玩家行为回传LLM推进剧情 | ⬜ |
| 4 捏人入坑 | 自建角色注入剧情 | ⬜ |
| 5 记忆与一致性 | 摘要记忆、角色状态持久化 | ⬜ |

参考项目：[WorldX](https://github.com/YGYOOO/WorldX)（一句话生成AI自主世界）——同路线的开源先行者，阶段3+可借鉴其 Agent 运行时设计。

目录纪律：临时产物只进 `temp/`（随时整删）；生成物在 `story-engine/worlds/`（不入库）；里程碑由用户喊"存档"后 git commit。
