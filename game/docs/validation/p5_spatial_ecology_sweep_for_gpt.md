## 观测缺口（诚实记录）

1. unknown_steps≡0 是**结构必然**而非行为事实：每 tick 先感知（视野≥3）再移动（步长 1），相邻步的目的格在本 tick 开局已被感知——"踩进未知"只可能发生在规划层（unknown_cost 影响路径选择），不可能发生在迈步层。人格差异由覆盖差体现（见 A）。要测"闯未知倾向"需记录规划路径中 UNKNOWN 格占比（未埋点）。
2. 夜间 movement_blocked、reacquired_en_route、replan 成功率（blocked 后 N tick 内成功迈步）未埋点——下轮 sweep 可加。
3. 绝望/饥饿为 24-tick 采样（日粒度）。
