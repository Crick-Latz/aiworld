## 机制改动（4 处最小接线，GPT 授权范围内）

```gdscript

_init_world_resources: bush.food = bush_capacity
_daily_update 再生:    bush.food = bush_capacity
_do_forage: got = mini(1, food)         # 每次采 1——多容量供多人分，不供单人搬空（§二）
```
